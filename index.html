Company

The company behind ZKProofport.

Masse Labs develops zero-knowledge circuits, mobile proving, SDKs, and verification tools. We bring these components together so teams can build applications around verifiable claims.

Our focus is practical integration: giving people and AI agents ways to prove what a service needs, while limiting the underlying credentials shared with that service.

ZKProofport

One product. Mobile, SDK, and agent tools.

Building blocks for requesting proofs, generating them, and checking the claims they carry.

Mobile

Generate supported proofs on iOS and Android. Proof computation runs on the device, and the app returns proofs and public outputs to the requesting service.

Mobile app overview
SDK

Developer SDK

Request proofs from the mobile app through QR codes or deep links, track requests, and integrate EVM verification into your application.

SDK integration guide
AI

Agent

Integrate server-side proof generation into AI workflows with APIs, a TypeScript SDK, and x402 payments.

Coinbase KYCProve possession of a supported Coinbase KYC attestation.
Country eligibilityProve that an attested country meets an inclusion or exclusion policy.
Email domainProve a verified email domain through supported Google or Microsoft credentials without sharing the full address.

Different execution paths, different data handling.

Mobile proving runs on-device. The hosted agent prover currently runs on standard servers, which process proof inputs. AWS Nitro Enclave support is implemented, but is not the current hosted deployment.

Verifying services receive proofs and public outputs. Privacy depends on the chosen proof path and the information those outputs reveal.
